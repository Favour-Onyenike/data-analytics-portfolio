## How I work on a project

1. **Define the problem** — business questions before tools  
2. **Understand the data** — tables, grain, quality issues  
3. **Clean & model** — Python for preparation, SQL for structure  
4. **Analyse & visualise** — metrics that answer the questions  
5. **Recommend** — actions tied to evidence
